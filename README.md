# py-ron

> Python app that generates Ron Swanson quotes on random photos from Unsplash.

## Overview

A Python application that combines Ron Swanson quotes with random photography from Unsplash to create motivational/meme images.

**Live demo**: https://aaronjones003.github.io/py-ron/

## Features

- Fetches random Ron Swanson quotes from ron-swanson-quotes.herokuapp.com
- Retrieves random photos from Unsplash API
- Generates composite images with quotes overlaid on photos
- Built with Python PIL for image processing

## Development

```bash
pip install -r requirements.txt
python app.py
```

Note: You'll need to add your Unsplash API client ID to the `clientId` variable.
